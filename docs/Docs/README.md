# 📚 Welcome to the Altime Project Docs!

This module gathers the support materials for the Altime system, built for time tracking of outsourced professionals.

Here you will find the essential documents for installing and using the system.

> This documentation was produced by 3rd-semester students of the Database Technology program at FATEC Profº Jessen Vidal – São José dos Campos, SP, Brazil.
